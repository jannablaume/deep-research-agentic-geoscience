# Architectures

Single-agent graphs with constrained nodes are described for TREMORS (LangGraph over ObsPy/FDSN) and for seismo-mcp (MCP servers wrapping seismology codes) [[doi:10.48550/arxiv.2609.01777]] [[title:seismomcp]]. [Certain]

A layered pipeline-with-agent is described for the Devito translator: knowledge-base construction, retrieval, conversion, quality validation, and a LangGraph decision layer [[arxiv:2601.18381]]. [Certain]

A hierarchical multi-agent stack is described for TRACE: planning, workflow instantiation, coding, result checking, and analysis/summary agents [[doi:10.48550/arxiv.2603.21152]]. [Certain]

GAIA is described as Agent plus Chat plus Digital Twin in an agentic RAG layout [[arxiv:2511.03852]]. [Certain]

Whether industry SPE/IPTC abstracts that say “agentic RAG” implement the same graph-plus-tools pattern cannot be read from the abstracts retrieved in this run [[doi:10.2118/229240-ms]] [[doi:10.2523/iptc-25122-ms]]. [Certain]
